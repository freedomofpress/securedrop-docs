# After you submit

## Continuing the conversation

If you have previously submitted a message or file to an organization's SecureDrop and would like to check for responses, click the **Log in** button on the media organization's SecureDrop page.

![Example home page of a SecureDrop instance.](../images/manual/screenshots/source-index.png)

The next page will ask for your secret codename. Enter it and click **Continue**.

![Example login page asking you to enter your secret codename.](../images/manual/screenshots/source-enter-codename-in-login.png)

If a Journalist has responded, their message will appear on the next page. Before leaving the page, you should delete any replies. In the unlikely event that someone learns your codename, this will ensure that they will not be able to see the previous correspondences you had with Journalists.

![Example submission page, displaying a reply from a journalist.](../images/manual/screenshots/source-checks_for_reply.png)

After you delete the reply from the Journalist, make sure you see the confirmation message: "Reply deleted".

![Example submission page, displaying a confirmation message after a reply was deleted.](../images/manual/screenshots/source-deletes_reply.png)
