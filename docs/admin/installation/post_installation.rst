Post-installation
=================

You have now completed and tested your SecureDrop installation. Consult the rest of this Admin Guide for post-installation steps:

- To create your first Journalist user and, if necessary, provision additional Workstations, see the :doc:`Onboarding section</admin/onboarding/index>`.
- For guidance on creating and publishing a Landing Page for your SecureDrop, see the :doc:`Publishing your SecureDrop section</admin/publish/index>`.
- Please review the :doc:`Maintenance section</admin/maintenance/index>` for an overview of how to maintain your SecureDrop and troubleshoot any issues that may arise.
- The :doc:`Reference section</admin/reference/index>` contains additional reference material for Administrators on how to use the system.
