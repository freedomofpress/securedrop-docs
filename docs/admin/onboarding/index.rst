**************
Onboard users
**************

SecureDrop allows an organization to have multiple Journalists and multiple Administrators, using individual or shared laptops. 

During the initial :doc:`installation</admin/installation/index>` of SecureDrop, only the first Administrator user is created. You can onboard additional Journalists and Administrators as needed.

The following pages describe all the procedures needed for onboarding and offboarding either type of user.
